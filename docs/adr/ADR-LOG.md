# ADR Log

Agent-facing index of accepted decisions that still constrain further work and that intuition would likely get wrong. Each entry names the decision and why it is deliberate; detail lives in the linked canonical docs. Implemented decisions stay listed only while a file cites their ID; trivial or superseded ones are not listed, and no ID is reused.

Policy: entry length ([rule 10](../../AGENTS.md#documentation-policy)), decision flow and hygiene rules live in [AGENTS.md](../../AGENTS.md#decision-flow).

Format: `ID | date | status | decision — canonical context`

The only product TypeScript is Watershed's pi extension, because pi loads only JavaScript or TypeScript extensions; it runs inside the user's own pi. Liquid never bundles pi or Node, also not for office users: the user installs pi (ADR-0219) — [TESTING.md](../../TESTING.md#development-toolchain), [liquid/README.md](../../liquid/README.md#run).

- **ADR-0069 / ADR-0141 / ADR-0182** | 2026-07-22–2026-10-04 | Accepted; planned for M3 | Replicas form a star around one Sync Server, not peer to peer. Sync merges only durably committed changes through an established CRDT library, without custom conflict logic (ADR-0182) — [V-Spec](../concept/V-Spec_Liquid.html#sync), [client architecture](../concept/liquid-client-architecture.md).

- **ADR-0163 / ADR-0200 / ADR-0201 / ADR-0218 / ADR-0226** | 2026-09-06–2026-10-31 | Accepted | Support is per product and capability, not a workspace-wide promise. Liquid's macOS releases ship without the App Sandbox, which would block starting the user's agents — [PLATFORMS.md](../../PLATFORMS.md), [liquid/README.md](../../liquid/README.md#run).
- **ADR-0184 / ADR-0185 / ADR-0215** | 2026-10-05–2026-10-27 | Accepted; service mode planned | Ahead of M2 and M3a the Meta-Harness core runs inside the Liquid app process, yet the core, never the Liquid UI, owns agent processes. - **ADR-0186 / ADR-0213 / ADR-0216 / ADR-0217** | 2026-10-05–2026-10-27 | Accepted | Liquid's Rust–Flutter bridge stays flutter_rust_bridge v2 while it holds the client architecture invariants; the Workspace crosses it only through a few message-shaped calls, so replacing it touches only those. - **ADR-0189 / ADR-0195 / ADR-0206 / ADR-0210 / ADR-0222** | 2026-10-23–2026-11-03 | Accepted; implemented in the agent-surface slice | pi's session files are the authoritative store on their host; the Workspace holds only a portable copy. - **ADR-0223 / ADR-0224** | 2026-10-30 | Accepted; target, planned for M3 | Agents act with their own identity and a grant the person signs (area, actions, expiry), never with more authority than that person, and write only through the Workspace CLI/API; revoking the grant makes the Sync Server refuse further changes (ADR-0223). - **ADR-0225 / ADR-0227** | 2026-10-30 | Accepted; planned | Unlike T3 Code, Watershed keeps harness configurations centrally and across devices: Liquid edits and stores them per harness, and Meta-Harness materializes them per session into a home it owns, linking the user's credentials, which never leave the host; changes are approved, audited proposals (ADR-0227). Every harness can use local inference, and an area may be kept to local models (ADR-0225) — [Meta-Harness V-Spec](../concept/V-Spec_MetaHarness.html#config).
- **ADR-0228** | 2026-10-30 | Accepted; target, attachments and area keys from M3 | Liquid ships native apps only. Devices encrypt per area, with a recovery key and dedicated key tests, because a fault there loses data — [V-Spec](../concept/V-Spec_Liquid.html#model), [sync](../concept/V-Spec_Liquid.html#sync).
- **ADR-0229** | 2026-10-30–2026-11-08 | Accepted; target | Liquid AI is a built-in agent profile on an agent host, limited to Liquid actions. - **ADR-0230** | 2026-10-30 | Accepted; target, from M3 | An agent reply shows Liquid content as a reference, never a copy: a Page or Block with a revision, which Liquid renders from the person's replica with the Page's own Block View, or as a placeholder without access; the Workspace CLI/API returns a ready reference for every change, so any harness can cite it.
