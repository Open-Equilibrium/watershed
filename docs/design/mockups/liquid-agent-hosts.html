Agent hosts

Step 4 of the T3 Code track (ADR-0299, ADR-0300): Liquid on one device uses the agents of another of the person's hosts. T3 Code's desktop app does the same under Settings → Environments → Add environment with a pairing code; Liquid keeps its own term, agent host (GLOSSARY.md). Choosing the host for a new session copies T3's environment picker in the Chat (ADR-0295) and needs no mockup.

1. Settings → Agent hosts

A new section after Writer model. This device's own Meta-Harness comes first; paired hosts follow with their Tailscale address and whether Liquid reaches them now. The row menu (···) offers Remove…, which forgets the host here and asks it to revoke the device's token. Status shows a word, never color alone.
