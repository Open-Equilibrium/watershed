Mockups for the M3a slice in PLAN.md, approved by the maintainer on 2026-11-01. The built parts (the Explorer, a blank Page, the first action, slash commands and the PowerBar) are removed here; their rules are in the V-Spec. What remains follows the V-Spec and guidelines.md. Views and the deletion cascade are in the Blocks mockups, Workspace settings in the Workspace settings mockups.

Revised by ADR-0239 and ADR-0241: the rail with Inbox and Settings, the Workspace switcher in the sidebar's top row, tabs side by side, Chats in place of agent sessions and Notion's scale are in the app's structure; this file keeps its slice's content, and the shell is redrawn as each slice is built.

6 · Text shortcuts

Notion's Markdown shortcuts set the current Paragraph's formatting: #, ##, ### headings, - bullets, 1. numbers, [] to-dos, > a toggle, " a quote, **bold**, *italic*, `code` and @ a link to a Page or Block. A toggle is formatting, not a Block. Two shortcuts end the Section instead: --- starts a new Section below a divider (see the Section mockups), and ``` starts a Code Block, which ends the Section like any other Block type.

7 · Embed

Embeds come with the built-in browser (M3b) and load remote content only after a click. A pasted link stays a link in its line (ADR-0305).

8 · The same Page on a phone

The order of Blocks is the same on every device. On a phone every Block stacks in Page order and stays visible; a Database, a Whiteboard and Code show a preview that opens a focused full-screen surface. Arrange mode on a phone starts with a long press. Arrange mode itself is built (ADR-0312).

Decisions

Decided (ADR-0235)

  1. Each area has its own heading in the Explorer, with nested Pages; Sources are peers in the same tree.
  2. A pasted URL is a link that fetches nothing; an embed loads only after a click.

Approved with these mockups (2026-11-01)

  1. The deterministic first-action mapping (its table is built and removed here), including a dropped CSV becoming a Database copy and ``` starting a Code Block.
  2. Database Views are Table, Board and Calendar; the Code Block shows code and never runs it.
  3. Phones stack every Block in Page order.
  4. ⇧⌘N creates a new Page in the current area; ⌘N stays with agent sessions.

Added on request, approved the same day

  1. Page icons beside the title, with Emoji and Icons tabs; uploaded images come later.
  2. Automations, History and Settings sit together at the Explorer's foot and open as dialogs; Roles live in Settings.
  3. The PowerBar searches without a prefix and understands / and >; @ stays reserved for people; "Add Block" is gone from its list.
