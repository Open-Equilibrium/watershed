Liquid: Tables and their Views

For the slice in PLAN.md, after ADR-0309. A Table holds the data and lives in the sidebar. What sits on a Page is always a View of it, with its own title, sort and filter.

1 · A View on a Page, and Tables in the sidebar

The block has one title, the View's. The note always names the Table. The sidebar's Tables section lists every Table in the Workspace, whichever area it belongs to.

2 · Where the note sits

Neither place adds a line.

A · Beside the titleRecommended, always in view
B · In the footer, beside the row count

3 · Two names, each edited in place

A click on the title changes this View only. A click on the note renames the Table, so nobody has to open it for that. A new Table starts with the first title typed as its name too; after that the two are separate.

Editing the View's title
Editing the Table's name

4 · Opening a Table from the sidebar

Optional, since everything can be done from a View. It shows all rows, unsorted and unfiltered, and where the Table is shown. Its ··· menu holds Delete Table….

5 · Adding a View

The slash command Table makes a new Table with its first View; Existing Table… picks one. A View starts with no sort or filter, and can copy them once from a View the person has access to. The two stay independent afterwards. If the Table has no other View, the question is skipped.

6 · Deleting

Deleting a View while the Table has others asks nothing. Deleting the last one asks first. Every deletion is one Action that a revert restores.

7 · When a View cannot show its Table

The View stays with its title. Without access, the note does not reveal the Table's name.

Decisions for this mockup

  1. The note: beside the title (A, recommended) or in the footer (B)?
  2. The last View: Delete or Cancel (1, approved), or may the Table stay in Tables (2, recommended)? The V-Spec counts a full-page representation as a View, so with 2 a Table’s entry in Tables is itself a View and no Table is ever orphaned; ＋ in Tables can then make a Table before any Page shows it. With 1, that entry must not count as a View, and Tables has no ＋.
