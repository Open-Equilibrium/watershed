Liquid Workspace: Media Block

Mockups for the Media Block, the next built-in Block in PLAN.md. They detail the Media Block of the approved Pages mockups (section 4) and Blocks mockups: an image or a file, which becomes an attachment of the Workspace (ADR-0228), kept encrypted in the replica. A pasted link is not a Media Block but a link in its line, as in Microsoft Loop (section 6); embeds come with the built-in browser of web-link Sources (M3b, ADR-0236). The frame and the slash commands follow the Code Block. Approved by the maintainer on 2026-11-17.

1 · Media on a Page

An image shows at its own size, never wider than the text column and never enlarged. A file is one line: its name, and at the line's right end its size and type. Hovering over a Media Block shows a small bar at its top right (section 3).

2 · Adding media

The slash commands list Media under Blocks, which are now in alphabetical order; typing filters them as before. Media opens the system's file dialog straight away: the chosen files become Media Blocks in place of the empty line, and cancelling leaves the line as it was, so there is no empty Media Block. Dropping files on a Page adds one Media Block per file where the blue line shows; pasting an image adds one below the line, or in place of an empty line.

3 · The bar

Save as… writes a copy of the file where the person chooses, through the system's save dialog; Liquid opens no attachment in another app yet, as that leaves an unencrypted copy outside the Workspace (decision 4). ⋯ holds Save as… and Delete, which removes the Block in one Action, until Block handles come (decision 6).

4 · Large files and refusals

A large file is written in parts, so the Page stays usable: the Block shows how much is in, and other Blocks can be edited meanwhile. A file over 5 GiB is refused with its reason, as the core refuses other writes past its caps (ADR-0251). An image Liquid cannot show, such as HEIC on some systems, appears as a file.

5 · Next to a Media Block

The caret passes over a Media Block as it passes over a Table: ↑ at the start of the Text Block below goes to the Text Block above it. ⌫ at the start of the Text Block below joins nothing, and a numbered list after it starts at 1 again. A Liquid version without Media Blocks shows one as the placeholder of ADR-0245.

6 · Pasted links, later

Not in this slice: a pasted link stays in its line, as Microsoft Loop shows one: an icon and the link's title inside the text, which a click opens in the default browser. Loop fetches the page's title and icon; Liquid fetches nothing, so the title is the link text the clipboard carries, as a link copied from a page has, else the link's host, and the icon is Liquid's link icon. Hovering shows the address with Edit, which changes the title and the address, and Copy link. A link is an inline mark, so it comes with the inline marks of Text Blocks; until then a pasted link is text.

Decisions

Approved (2026-11-17)

  1. An attachment's bytes live inside the encrypted replica, in parts of at most 1 MiB, named by their contents' SHA-256, so one file added twice is kept once; rule 15 of the client architecture changes accordingly. Sync encrypts them with area keys later (M3c).
  2. Files come in through file_selector (the dialog), desktop_drop (dropping) and super_clipboard (pasting images and code), as AppFlowy does, with the Flutter team's dialog package.
  3. A Media Block holds an image or a file of at most 5 GiB. Embeds follow with the built-in browser (M3b); a pasted link becomes a link in its line, as in Loop, with inline marks (section 6).
  4. Save as… is the only way out of the Workspace for now; opening an attachment in another app waits for the drive view's OS integration (ADR-0228), which keeps decrypted copies under Liquid's control.
  5. Images Flutter decodes (PNG, JPEG, GIF, WebP, BMP) show as images, decoded at the size shown so memory stays bounded; anything else shows as a file. Captions, resizing and alignment come with Arrange mode.
  6. ⋯ › Delete removes a Media Block until Block handles that delete any Block come; its bytes stay in the replica until purge comes with History (ADR-0250).
  7. The slash command Media opens the file dialog at once; there is no empty Media Block. The Blocks in slash commands are in alphabetical order.
  8. Pasted code becomes a Code Block when the clipboard marks it as code: the editor data VS Code and its forks put there, which also name the language, or HTML that is a single pre element.
  9. On a phone, a Media Block shows as it does here; the phone client comes later.
