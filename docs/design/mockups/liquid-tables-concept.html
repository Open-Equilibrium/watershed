Liquid Workspace: Tables, formulas and reports

A concept approved by the maintainer on 2026-11-03 (ADR-0244): one table concept for Notion's databases and Excel's workflow, with formulas that need no arranging. It builds on the approved Table View and Blocks mockups, ADR-0235's formula language (Excel's function names, references as chips bound to stable IDs) and ADR-0242/0243. Excel's own answer to "database or sheet" is its Tables (Ctrl+T): typed columns, calculated columns, a total row and references by name. Liquid's table is that, with Notion's Views on top.

1 · One concept: a Table with Views

The Block is called Table everywhere, as in Airtable; Table, Board and Calendar are its Views, as Notion's database views. There is no second, "simple" table as Notion has: a Table starts as light as a grid and grows into a database by adding Views, links and formulas. Internally it stays the Database Block.

2 · The total row: "Sum:" without arranging anything

The table's footer is its total row, as in Excel Tables and Notion's Calculate: each field's footer cell picks Sum, Average, Count, Min, Max, Empty or Filled, or takes its own formula. It counts what the View shows, so a filter changes it. Grouped Views add the same row per group as subtotals.

3 · A calculated field

A formula field computes one value per row from the row's other fields, as Excel's calculated columns and Notion's formula properties do. Typing a field's or Table's name offers it as a chip, so renaming "Amount" keeps the formula.

4 · A formula inside a sentence

= in a Text Block inserts a live value into the text, as Coda does: the label and the value are one sentence and one Block. A click on the value shows its formula.

5 · Reports in Excel's layout

A budget, an offer or a P&L lists labels on the left and values on the right, with subtotals. Three ways to build that; the maintainer chose A.

6 · A new field finds its kind, as in Excel

+ adds a field at once, without asking for a kind. The first value typed or pasted decides it: digits make a number, a day a date, anything else text; a note says so and offers to change it. Pasting from Excel or a CSV does the same per column. Changing a kind later converts the values that fit and keeps the others visible as text.

Decided on 2026-11-03

  1. The Block is a Table with Views, as Airtable; the core keeps calling it the Database Block.
  2. Reports in Excel's layout are a Calculation Block (section 5, A).
  3. A new field finds its kind from its first value and can change it later (section 6); the first Table View keeps the approved kind menu until the core can change a field's kind.
  4. Whether a row opens as a Page is decided with the Views slice.
