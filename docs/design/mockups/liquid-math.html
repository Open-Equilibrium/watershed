Liquid Workspace: Math

Mockups for the Math slice in PLAN.md (ADR-0316): a Math Block shows one LaTeX formula typeset, and $…$ in a Text Block sets one inside a sentence, as Notion and Obsidian do. Math is shown, never computed; Calculation Blocks compute. Liquid typesets with flutter_math_fork, a pure-Dart port of KaTeX, so the commands KaTeX knows work. The shell is the one in the Pages mockups.

1 · A Math Block, and writing one

The formula stands centred on its own line. A click opens its LaTeX; two ways to show it, A recommended.

2 · Math inside a sentence

Text between two dollars becomes math once the caret leaves it, as in Obsidian and Typora; the caret inside shows the LaTeX again. The Text Block keeps plain text with the dollars, so copying, searching and Markdown keep it as written. A dollar opens math only when a character other than a space follows it, and closes it only after one, never before a digit, as Pandoc reads Markdown: "$5 and $10" stays text.

3 · Adding math, and a formula that cannot be set

/Math in the slash menu or the PowerBar adds a Math Block; $$ at the start of an empty Text Block turns it into one, as ``` makes a Code Block, and ⌫ in an empty Math Block turns it back. LaTeX that cannot be set shows as written, faint, with KaTeX's reason below.
