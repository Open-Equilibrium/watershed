Liquid Workspace: Text formatting

Approved by the maintainer on 2026-11-22 (ADR-0317). Formatting marks in a Section never hide state: the word holding the caret shows its Markdown, as T3 Code's composer does, and every mark can be seen, ended and removed. Sections and Paragraphs are in the Section mockups.

4 · One action clears everything

⌘\ (Ctrl+\ on Windows and Linux) removes every mark in the selection, as in Google Docs; Clear formatting in the selection's context menu does the same, and Settings → Shortcuts can move the shortcut, since keyboards such as German ones reach \ only with ⌥ or AltGr. An empty mark, such as a link without text, is removed on its own.

Decisions

Approved (2026-11-22)

  1. Visible marks. Only the styled word holding the caret shows its Markdown, as in T3 Code, never the whole line as in Obsidian.
  2. Edges. Two caret stops at a styled edge; bold, italic and strike grow inside, links and code never.
  3. Clearing. ⌘\ or Ctrl+\, Clear formatting in the context menu and a movable shortcut; empty marks go on their own.
  4. Markdown in and out. Copy writes Markdown as plain text; pasted Markdown becomes Paragraphs and marks. A selection that crosses another Block takes it whole, and a Table copies as a Markdown table.
  5. No underline. Markdown has none, as T3 Code leaves it out.
