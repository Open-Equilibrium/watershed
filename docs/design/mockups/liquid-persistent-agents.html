Persistent agents in Liquid

Liquid's screens for Agent profiles (ADR-0283). Meta-Harness already provides them: meta agent create, routines that wake the agent's current thread, a private memory folder, and a new thread when the context is 80% full. The agent Chat itself stays T3's. These screens add only what T3 lacks.

A · Sidebar and an agent's Chat

An Agents section sits above Threads. Each row shows the agent's state, in the words the session rows use, or when it next wakes up. Selecting an agent opens its current thread in the usual Chat. The session card gains an Agent section (instructions, memory folder, earlier threads) above T3's Automations, which list the agent's routines.
