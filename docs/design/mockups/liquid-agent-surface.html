1 · Agent view

The sidebar shows project, harness, branch and device per session. Widgets sit directly above the input area, which keeps one position and height in every tab; approvals appear inside it and keep the draft.

2 · Trajectory

One overview timeline on top; dragging focuses a range and dims steps outside it. Steps are grouped by turn, and the selected step expands in place. The session graph on the right draws one line per branch and one dot per step; a click or ⌥↑↓ jumps to a step.

3 · Compare

Both branches share one time axis, followed by metrics and aligned steps. Checkboxes in the graph select the two branches.

4 · Diff

A run's changes against the project before the run. The file list is a collapsible folder tree, and only the file header shows the full path. Branch and commit actions follow in the next slice.
